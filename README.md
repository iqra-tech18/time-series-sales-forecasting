# time-series-sales-forecasting
## Project Overview
This project focuses on forecasting retail and restaurant sales using Time-Series Analysis and Machine Learning techniques.

## Objectives
- Reduce food waste
- Improve stock availability
- Support labor scheduling
- Predict future sales trends

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Prophet
- Google Colab

## Project Workflow
### Week 1
- Data cleaning
- Time-series EDA
- Trend analysis
- Seasonality analysis

### Week 2
- Feature engineering
- Lag features
- Rolling averages

### Week 3
- Model training
- Random Forest
- XGBoost
- Prophet

### Week 4
- Forecast evaluation
- MAE & RMSE analysis
- Visualization
